# Forget It — and the platform around it

A tiny multi-tenant Go service for capturing stray thoughts, ideas, links, and news, and resurfacing them at random.

The real point of this repo is the platform around the app, built layer by layer as hands-on preparation for senior SRE / platform engineering interviews:
Terraform, Kubernetes, GitHub Actions, Kafka, the Grafana observability stack, SLOs, k6, Argo CD, AWS (IAM, EKS), and AI-assisted operations.

- `PLAN.md` — what's next
- `PROGRESS.md` — daily log
- `weekly/` — weekly summaries
- `design/` — system design practice and ADRs
- `break-fix/` — post-incident reviews of deliberately broken systems
- `COACH.md` — how the daily coaching sessions work
